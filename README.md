# 🏗️ Мониторинг конкурентов — Инъекционная гидроизоляция (AI Конкурентная разведка)

Автоматизированный сервис для проведения конкурентной разведки и маркетингового анализа в узкоспециализированной строительной нише: **инъекционная гидроизоляция фундаментов, подвалов, паркингов, бассейнов, лифтовых шахт, бетонных конструкций и деформационных швов**.

## 🎯 Кейс и Проблематика

В нише подземной гидроизоляции и усиления бетона конкурентный анализ требует учета специфических строительных факторов:
- Технологии работы (пакеры, смолы, акрилатные гели, микроцементы, отсечная гидроизоляция).
- Оценка коммерческого доверия (наличие допусков СРО, лицензий, примеров реальных объектов, видео с процессов инъектирования).
- Конверсионный потенциал сайтов и креативов (калькуляторы расчета расхода материалов, быстрый выезд инженера).
- Гипотезы для рекламы (контекстная реклама в Яндексе, таргетированная реклама для девелоперов, генподрядчиков и частных домовладельцев).

---

## 🚀 Основной функционал

1. **Парсинг через Selenium (Headless Chrome)**:
   - Загрузка динамического сайта конкурента.
   - Извлечение `title`, `meta description`, `h1` и полного текста `document.body.innerText` (ограничение до 20 000 символов).
   - Создание полноразмерного скриншота страницы и автосохранение файла с меткой времени в каталог `data/screenshots/`.
2. **Адаптированные промпты для LLM / Vision API**:
   - Оценка текста, изображений и сайтов конкурентов в строительной специфике.
   - Все числовые метрики строго от **0 до 10** (`design_score`, `animation_potential`, `conversion_potential`, `trust_score`).
   - Массивы рекомендаций, УТП, рекламных гипотез строго по **3–5 пунктов**.
   - Ответы модели строго в чистом формате JSON.
3. **Обновленный веб-интерфейс (Frontend)**:
   - Отображение сетки оценок с цветными бейджами.
   - Четко структурированные блоки: сильные/слабые стороны, УТП, рекламные гипотезы (`ad_hypotheses`), рекомендации и текстовые выжимки.
   - Просмотр истории последних 10 запросов.

## 🛠️ Установка и Запуск

### 1. Клонирование и виртуальное окружение

```bash
git clone https://github.com/your-username/competitor-monitor.git
cd competitor-monitor

python -m venv venv

# Windows
venv\Scripts\activate

# Linux / Mac
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Конфигурация (.env)

Создайте файл `.env` в корне проекта (убедитесь, что `.env` внесен в `.gitignore`). Вы можете выбрать один из удобных вариантов подключения к AI:

```env
# ==============================================================================
# Вариант 1: Прямой доступ к OpenAI через HTTP/HTTPS прокси (рекомендуется)
# ==============================================================================
OPENAI_API_KEY=sk-proj-your_openai_api_key_here
PROXY_URL=http://user:password@host:port

# ==============================================================================
# Вариант 2: Через российский агрегатор ProxyAPI (https://proxyapi.ru/)
# ==============================================================================
PROXY_API_KEY=your_proxy_api_key_here
PROXY_API_BASE_URL=https://api.proxyapi.ru/openai/v1

# ==============================================================================
# Общие настройки приложения и парсера
# ==============================================================================
OPENAI_MODEL=gpt-4o-mini
OPENAI_VISION_MODEL=gpt-4o-mini
API_HOST=0.0.0.0
API_PORT=8000
PARSER_TIMEOUT=30
```

> 💡 **Примечание по парсеру:** Selenium парсер открывает сайты конкурентов напрямую с локального IP для максимальной скорости загрузки и стабильности на сайтах РФ, а прокси используется для обращений к OpenAI API.

### 3. Запуск веб-сервера

Запуск через виртуальное окружение:

```bash
# Windows
venv\Scripts\python run.py

# Linux / Mac
python run.py
# или
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

После запуска интерфейс доступен по адресу: **http://localhost:8000**
Документация Swagger: **http://localhost:8000/docs**

## 📁 Структура проекта

```
competitor-monitor/
├── .clinerules              # Системный контекст и правила для AI
├── .gitignore               # Исключения Git (включая .env, venv, data/screenshots)
├── data/

├── backend/
│   ├── main.py              # FastAPI роуты (/analyze_text, /analyze_image, /parse_demo, /history)
│   ├── config.py            # Загрузка конфигурации из .env
│   ├── models/
│   │   └── schemas.py       # Pydantic модели (CompetitorAnalysis, ImageAnalysis, ParsedContent)
│   └── services/
│       ├── openai_service.py# Интеграция с OpenAI/ProxyAPI (чистый JSON, оценки 0-10)

│       └── history_service.py# Локальная история запросов
├── frontend/
│   ├── index.html           # Интерфейс
│   ├── styles.css           # Стили (бейджи оценок, карточки, грид)
│   └── app.js               # Динамический рендеринг результатов и запросы к API
├── history.json             # Сохраненная история
├── README.md                # Описание кейса и документация
├── requirements.txt         # Зависимости Python
└── run.py                   # Точка входа для запуска
```
