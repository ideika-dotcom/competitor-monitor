# 🖥️ Мониторинг конкурентов — Desktop App (Инъекционная гидроизоляция)

Десктопное приложение на PyQt6 для конкурентной разведки в нише инъекционной гидроизоляции.

## 📋 Требования

- Python 3.9+
- PyQt6, requests, Pillow
- Запущенный backend-сервер (`python run.py`)

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd desktop
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
# В корне проекта (терминал 1):
python run.py

# В папке desktop (терминал 2):
python main.py
```

## 📦 Сборка в .exe (PyInstaller)

Для сборки автономного `CompetitionMonitor.exe`:

```bash
cd desktop
python build.py
```

Готовый файл появится в `desktop/dist/CompetitionMonitor.exe`.

Для очистки временных файлов сборки:
```bash
python build.py clean
```

## 🎨 Функционал

- **Адрес API**: Поле вверху окна с сохранением в `settings.json`.
- **📝 Анализ текста**: Анализ офферов и описаний услуг по гидроизоляции.
- **🖼️ Анализ изображений**: Drag & Drop загрузка скриншотов сайтов и рекламных баннеров.
- **🌐 Парсинг сайта**: Автоматическое извлечение текста и анализ по URL.
- **📋 История**: Просмотр и очистка предыдущих запросов.
- **Проверка сервера**: Предупреждение и индикация при недоступности бэкенда.

## 🔧 Структура

```
desktop/
├── app.py           # Главное окно PyQt6 (QMainWindow, 4 вкладки, логика API)
├── main.py          # Точка входа в приложение
├── build.py         # Скрипт сборки PyInstaller (--onefile --windowed)
├── settings.json    # Файл сохранения настроек (адрес API)
├── requirements.txt # Зависимости
└── README.md        # Инструкция
```
